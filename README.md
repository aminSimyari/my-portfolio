# My Portfolio

This repository contains the source code for my personal portfolio website. I built this project to showcase my skills in frontend Engineering and highlight the projects I have worked on.

## Technologies Used

- Vue 3
- Vite
- Tailwind CSS
- TypeScript

## Key Features

- Responsive design for mobile, tablet, and desktop screens
- Support both English and Farsi
- Toggle theme

## Local Development

To run this project on your local machine:

1. Clone the repository:
  
   git clone https://github.com/aminSimyari/my-portfolio.git
  

2. Install dependencies:

   npm install


3. Start the development server:
   
   npm run dev
